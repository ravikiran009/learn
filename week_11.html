Day 71 RAG: Text Chunking, Vector DBs & Cross-Encoder Reranking

71.1 Two-Stage Retrieval Architecture

Stage 1: User Query -> Embeddings -> ANN Search (HNSW Index in ChromaDB / pgvector) -> Top 100 Candidates (Fast) Stage 2: Top 100 Candidates -> Cross-Encoder Reranker (ms-marco) -> Top 5 Most Relevant Chunks -> LLM Prompt

71.2 Cross-Encoder Reranking Implementation

from sentence_transformers import CrossEncoder

reranker = CrossEncoder("cross-encoder/ms-marco-MiniLM-L-6-v2")
# Returns direct query-document relevance scores
scores = reranker.predict([(query, doc) for doc in candidate_chunks])
top_5_contexts = [doc for _, doc in sorted(zip(scores, candidate_chunks), reverse=True)[:5]]
Day 72 Fine-Tuning: LoRA, QLoRA & PEFT

72.1 LoRA (Low-Rank Adaptation)

Instead of fine-tuning all 7 Billion parameters of a model, LoRA freezes base weights $W$ and trains two small rank decomposition matrices $A$ ($d \times r$) and $B$ ($r \times d$) where rank $r \ll d$. Reduces trainable parameters by 1,000$\times$!

from peft import LoraConfig, get_peft_model, TaskType

config = LoraConfig(
    task_type=TaskType.CAUSAL_LM,
    r=16, lora_alpha=32,
    target_modules=["q_proj", "v_proj"],
    lora_dropout=0.05
)
model = get_peft_model(base_model, config)

Day 74 LLM Evaluation: RAGAS & Hallucination Mitigation

74.1 Core RAGAS Metrics

  • Faithfulness: Measures if the generated answer is strictly grounded in the retrieved context chunks (detects hallucinations).
  • Answer Relevancy: Measures if the answer directly addresses the original user question.
  • Context Recall: Measures if the retriever successfully fetched all relevant knowledge needed for the ground truth answer.

Day 77 Production LLM Architecture Review
Q: When should you use RAG vs Fine-Tuning for a enterprise AI assistant?
A: Use RAG when the assistant needs access to dynamic, frequently updated, or private domain knowledge. Use Fine-Tuning when you need to change the model's output style, tone, format (e.g. strict JSON output), or specialized domain language.
