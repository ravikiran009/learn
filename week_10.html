Day 64 Linear Algebra, Probability, Statistics & Optimization

64.1 Cosine Similarity & Softmax Formula

Cosine Similarity: $\text{cos}(\theta) = \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\| \|\mathbf{v}\|}$ (Used for embedding vector similarity in vector databases).

Softmax Function: $\text{Softmax}(z_i) = \frac{e^{z_i}}{\sum_{j} e^{z_j}}$ (Converts unnormalized logit scores to probability distribution).

64.2 Gradient Descent Update Rule

$$\theta \leftarrow \theta - \alpha \nabla L(\theta)$$

Day 65 Classical ML: Regression, Ensembles & Bias-Variance Tradeoff

65.1 Random Forest (Bagging) vs XGBoost (Boosting)

  • Bagging (Random Forest): Trains multiple decision trees independently on random bootstrap sub-samples to reduce Variance (overfitting).
  • Boosting (XGBoost / LightGBM): Trains decision trees sequentially where each tree corrects errors of previous trees to reduce Bias (underfitting).
Day 66 Neural Networks: PyTorch, Loss & Backpropagation

66.1 PyTorch MLP Implementation

import torch
import torch.nn as nn

class MultiLayerPerceptron(nn.Module):
    def __init__(self, input_dim, hidden_dim, num_classes):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(input_dim, hidden_dim),
            nn.GELU(),
            nn.Linear(hidden_dim, num_classes)
        )

    def forward(self, x):
        return self.net(x)
Day 67 Training Mechanics: AdamW & Layer Normalization

67.1 AdamW & LayerNorm in Transformers

AdamW: Decouples weight decay regularization from gradient updates, stabilizing transformer optimization. Layer Normalization: Normalizes features per token rather than across mini-batches.

Day 68 Transformers: Tokenization, Self-Attention & RoPE

68.1 Scaled Dot-Product Self-Attention Formula

Attention(Q, K, V) = Softmax( (Q × Kᵀ) / √d_k ) × V

Query ($Q$), Key ($K$), and Value ($V$) linear projections enable every token to dynamically focus on all contextual tokens across the sequence.

Day 69 Inference Optimization: KV Cache, Quantization & vLLM

69.1 KV Cache Acceleration

During autoregressive decoding, storing Key ($K$) and Value ($V$) tensors reduces generation time complexity from $O(N^2)$ to $O(N)$, eliminating redundant matrix recalculations!

69.2 PagedAttention (vLLM)

vLLM introduces PagedAttention, which manages KV cache tensors in non-contiguous virtual memory blocks (pages), eliminating 60%+ memory fragmentation and enabling continuous batching!

Day 70 Transformer Code Workshop
Q: What is the main advantage of Rotary Position Embeddings (RoPE)?
A: RoPE encodes token positions by rotating Query and Key vectors in 2D complex planes. This maintains relative distance properties and allows models like LLaMA to extrapolate smoothly to longer context lengths beyond their training window.
